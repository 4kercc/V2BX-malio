## Go安装与编译

- 下载Go 1.24.2 ZIP，解压到 C:\Go
- MSI安装方式失败（静默安装后找不到Go），改用ZIP手动安装
- 默认代理 proxy.golang.org 不可达，改用 goproxy.cn
- 编译时遇到API错误（DialOptions/Dial/Rule结构等），原因是sing-box被replace为 wyx2685/sing-box_mod@v1.12.0-beta.17.2，API有差异
- 修复方式：
  - log.Warnf → log.Warn + fmt.Sprintf
  - option.DialOptions → option.DialerOptions（Inet4BindAddress用 *badoption.Addr）
  - option.DirectOutboundOptions 嵌入 DialerOptions，不通过 .Dial 字段
  - Rule 使用 Type=default + DefaultOptions（RawDefaultRule.Inbound + RuleAction{RouteOptions{Outbound}}）
  - controller.go: c.ApiConfig.NodeID → node.Id（NodeInfo已含Id字段）
- 编译成功，产物 V2bX 约 133MB（Linux amd64 静态编译）

## 路由优先级修复

- 问题：sing_origin.json 中有兜底规则 `{"outbound":"direct","network":["udp","tcp"]}` 匹配所有流量，导致自动生成的节点规则（追加在末尾）永远不执行
- 修复：将自动生成的路由规则从 append 改为 prepend（插入到已有规则前面），确保 inbound 专用规则优先匹配
- 修改文件：core/sing/sing.go，先收集 autoRules，最后 `append(autoRules, existingRules...)`
